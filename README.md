# 🚀 Игра типа про росту
> Игра хоррор(нет). Сюжет таков вы попали в петлю, и должны найти 5 ключей и уйти от Полярного Скитальца который находится в Росте и Режет людей.

## 🛠️ Чо надо для запуска
* **Язык:** Python 3.14+
* **Скачать:** ursina pillow

## 🚀 Быстрый старт (Getting Started)

### Требования
Убедитесь, что у вас установлено:
Python 3.14+

### Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/mekesik/MurmanskGameBTWrosta
   ```
2. Перейдите в папку проекта:
   ```bash
   cd murmansk horror
   ```
3. Установите зависимости и запустите:
   ```bash
   python -m pip install ursina pillow
   murmansk_horror.py
   ```
